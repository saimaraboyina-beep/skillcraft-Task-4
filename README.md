# SkillCraft Technology — Task 4: Excel Sales Dashboard

## Project Overview
This project analyzes a Superstore-style sales dataset using Microsoft Excel and presents the results in an interactive-style sales dashboard.

## Objectives
- Analyze total sales and total profit
- Analyze profit by category
- Visualize sales trends over time
- Analyze sales by region
- Highlight high/low profit performers using conditional formatting
- Present the results in a clean dashboard

## Workbook Structure

### `Dashboard`
The final presentation dashboard containing:
- Total Sales
- Total Profit
- Number of Orders
- Average Order Value
- Profit by Category chart
- Sales Trend Over Time chart
- Sales by Region chart
- High/low performer guidance

### `Summary`
Analysis tables used to build the dashboard:
- Profit by Category
- Sales by Region
- Monthly Sales Trend
- KPI calculations

### `Data`
The cleaned source dataset used for the analysis.

## Tools Used
- Microsoft Excel
- Excel formulas
- Tables
- Charts
- Conditional Formatting

## Key Excel Techniques
- `SUM`
- `SUMIF`
- `SUMIFS`
- `AVERAGE`
- `COUNTA`
- Date-based monthly analysis
- Conditional formatting
- Dashboard charting
